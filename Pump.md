# Pump

Насос отсоса: пин `Pump_On` (PB13, выход push-pull), кнопка `Btn_Pump` (PB12, вход с подтяжкой к питанию). Модуль `App/Pump` (`pump.h` / `pump.c`).

## Полярность

- `Pump_On` — **активный низкий**: низкий уровень = насос включён, высокий = выключен.
- `Btn_Pump` — активная низкая: нажата = `GPIO_PIN_RESET`. Читается напрямую, без дебаунса.
- Начальный уровень `Pump_On` — **высокий** (насос выключен): задан в `.ioc` (`PB13.PinState=GPIO_PIN_SET`) и в `gpio.c`. Иначе насос был бы включён с момента сброса до `Pump_Init()`.

## Правило

Насос включён **⇔** `Btn_Pump` нажата **И** канал отсоса включён (`State_IsEnabled(CHANNEL_DESOLDER)`) **И** канал отсоса не заблокирован (`!Error_IsChannelBlocked(CHANNEL_DESOLDER)`).

| Условие | Насос |
|---|---|
| Кнопка не нажата | выключен |
| Канал отсоса выключен (UP+DN) | заблокирован |
| Любая неисправность канала отсоса (RTD КЗ/обрыв, обрыв нагревателя, «инструмент не подключен», код ошибки АЦП) | заблокирован |
| Неисправный БП (`Error_IsPsuFaultActive()`, блокирует оба канала) | заблокирован |
| Холодное жало | работает — температура не учитывается |
| Режим сна канала отсоса (PRESLEEP/SLEEP) | работает |

Никаких таймингов нет: ни задержки включения/выключения, ни ограничения непрерывной работы.

Нажатие `Btn_Pump` независимо от насоса считается активностью канала отсоса для `Sleep` (см. `Sleep.md`).

## Функции (`pump.h`)

| Функция | Назначение |
|---|---|
| `Pump_Init()` | Один раз после `MX_GPIO_Init()`. Выключает насос |
| `Pump_Poll()` | Из главного цикла, в 10 мс-гейте (`PUMP_POLL_MS`), после `Diag_Poll()`/`Control_Poll()` |
| `Pump_IsOn()` | true — насос сейчас включён |
