# Menu

Сервисное меню: два уровня доступа (**User** / **Expert**), навигация и редактирование параметров **текущего активного канала** (`InputFSM_GetActiveChannel()`).

Владелец экрана меню (не главного экрана) — вызывается из `fsm.c`, пока `InputFSM_GetScreenMode() == SCREEN_MODE_SERVICE`. `Fsm` сам перехватывает глобальные жесты выхода (короткие SET1/SET3, длинный аккорд UP+DN) **до** передачи события сюда — `Menu` их никогда не видит.

## Уровни

### User (уровень по умолчанию при входе в меню)

- **Выход**
- **Bzzz** — ON/OFF, глобальный флаг (`SETTINGS_FLAG_BUZZER_BIT`)
- **PreslipTime** — `Settings_GetPreSleepTimeout()`, канала
- **PreslipTemp** — `Settings_GetPresleepTemp()`, канала
- **Standby** — `Settings_GetSleepTimeout()`, канала
- **Сброс** — `Settings_ResetUserDefaults()` (с промтом подтверждения, см. ниже): пресеты 1/2/3, PreslipTemp, PreslipTime, Standby канала и глобальный флаг Bzzz — к дефолтам
- **Expert** — переход на уровень Expert

### Expert

Войти можно только **длинным SET2** на пункте "Expert": первое долгое нажатие показывает предупреждение (`Menu_IsShowingExpertWarning()`), второе долгое — открывает уровень. Короткое нажатие на "Expert" ничего не делает.

Пункты:
- **Выход** — обратно в User (**не** в главный экран)
- **Сброс** — `Settings_ResetExpertDefaults()` (с промтом подтверждения, см. ниже): Kp/Ki/Kd/Slope/Bias канала — к дефолтам
- **Kp / Ki / Kd / Slope / Bias** — параметры канала

## Навигация

- **UP/DN** — циклический выбор пункта текущего уровня, когда ничего не редактируется.
- **TOOLS** — переключает активный канал; обрабатывается в `fsm.c` **до** меню — `Menu` каждый раз читает `InputFSM_GetActiveChannel()` заново, сам TOOLS не видит и не обрабатывает.
- **SET2** — вход/выход из редактирования выбранного пункта (кроме Выход/Сброс/Expert — это пункты-действия, срабатывают сразу по короткому SET2, без отдельного режима редактирования).
  - В режиме редактирования: **Bzzz** — короткое UP/DN переключает ON/OFF; **числовые пункты** — короткое UP/DN ±1, длинное — многофазный авто-повтор (тот же алгоритм, что на главном экране): шаг 1 десять итераций → округление до ближайших 5 → шаг 5 пять итераций → округление до ближайших 10 → шаг 10 до отпускания (см. `accel_apply_step()` в `menu.c` и `Menu_Poll()`).

## Персист настроек

Изменения применяются в `Settings` сразу (клампятся там же), но физическая запись в EEPROM внутри самого меню не идёт по обычному отложенному пути (`Settings_Poll()`/`SETTINGS_SAVE_DELAY_MS`, как в главном рабочем экране, см. `Settings.md`) — вместо этого она форсируется **немедленно, одним разом**, в момент **полного выхода** из меню в главный экран (`fsm.c` вызывает `Settings_Save()` при возврате в `SCREEN_MODE_MAIN`).

Переход Expert → User (через пункт "Выход" на уровне Expert) **не** считается полным выходом — запись не форсируется.

## API (`menu.h`)

### Управление

| Функция | Назначение |
|---|---|
| `Menu_Init()` | Сбросить меню в начальное состояние: уровень User, курсор на первом пункте, редактирование выключено. Вызывать при каждом входе в сервисный экран (позиция/уровень между визитами не запоминаются) |
| `Menu_HandleEvent(ev)` | Разобрать одно событие кнопок. Вызывается из `fsm.c` вместо обычной обработки, пока экран в `SCREEN_MODE_SERVICE` — но только после того, как `fsm.c` проверил и обработал глобальные жесты выхода |
| `Menu_Poll()` | Продвинуть авто-повтор при удержании UP/DN в режиме редактирования числового параметра. Вызывать из `fsm.c` каждую итерацию главного цикла, пока экран в `SCREEN_MODE_SERVICE` (дёшево — сравнение по `HAL_GetTick()`, либо мгновенный выход, если не редактируем) |

Результат `Menu_HandleEvent()` — `menu_action_t`: `MENU_ACTION_NONE` или `MENU_ACTION_EXIT_TO_MAIN` (пункт "Выход" на уровне User — `fsm.c` должен переключить режим экрана и сохранить `Settings`).

### Для рендера (`Screen`)

| Функция | Назначение |
|---|---|
| `Menu_GetTitle()` | "Настройка Паяльник" / "Настройка Отсос" — по текущему активному каналу |
| `Menu_GetItemCount()` | Число пунктов в текущем уровне (6 для User, 7 для Expert) |
| `Menu_GetItemLabel(index)` | Название пункта по индексу (например "Bzzz", "Kp") |
| `Menu_GetItemValueText(index, buf, buf_size)` | Текстовое представление значения пункта (например "ON"/"OFF", "300"); пусто для пунктов-действий (Выход/Сброс/Expert) |
| `Menu_GetCursor()` | Индекс выбранного сейчас пункта текущего уровня |
| `Menu_IsEditing()` | true — значение выбранного пункта сейчас редактируется (UP/DN меняют его, а не курсор) |
| `Menu_IsShowingExpertWarning()` | true — показывается предупреждение перед первым входом в Expert |
| `Menu_GetExpertWarningLine(line_index)` | Строка предупреждения Expert, index 0..2 (три строки текста) |
| `Menu_IsShowingResetConfirm()` | true — показывается промт подтверждения пункта "Сброс" (после короткого SET2 на нём) |
| `Menu_GetResetConfirmLine(line_index)` | Строка промта подтверждения, index 0..2 (три строки текста) |
| `Menu_IsShowingResetDone()` | true — показывается сообщение "готово" после выполненного сброса, на `MENU_RESET_DONE_MS` |
| `Menu_GetResetDoneLine(line_index)` | Строка сообщения "готово", index 0 (одна строка текста, остальные — пустая строка) |

## Связь с другими модулями

- Рендерится через `Screen` (`render_menu()` в `screen.c`) — см. `Screen.md`.
- События кнопок и глобальные жесты выхода обрабатываются в `Fsm` — см. `FSM.md`.
- Значения читаются/пишутся через `Settings` — см. `Settings.md`.
