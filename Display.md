# Display

Модуль вывода на TFT-дисплей. Разделён на два слоя:

- **`display.h`** — общий контракт, не зависящий от конкретного контроллера. Верхний слой (графика/UI, `App/UI`) инклюдит только этот файл и не знает, какой чип физически стоит на плате.
- **`st7789.c` / `st7789.h`** — конкретная реализация для контроллера **ST7789** (интерфейс SPI1, DMA). `st7789.h` приватный — команды, биты MADCTL, тайминги — и не инклюдится ничем, кроме `st7789.c`.

Выбор реализации (ST7789 / другой контроллер, например ILI9341) делается на этапе компиляции — верхний слой от этого не зависит.

## Формат данных

Цвет пикселя — **RGB565** (16 бит), как того требует протокол ST7789/ILI9341. Сборка из 8-битных компонент — макросом `DISPLAY_RGB565(r, g, b)`.

## Основные операции (`display.h`)

| Функция | Назначение |
|---|---|
| `Display_Init()` | Аппаратный reset + init-последовательность контроллера |
| `Display_IsBusy()` | Идёт ли сейчас асинхронная DMA-передача |
| `Display_RegisterTxCpltCallback()` | Подписка на завершение DMA-передачи (вызывается из `HAL_SPI_TxCpltCallback`, из контекста прерывания — коротко, без повторного дёрганья SPI) |
| `Display_SetRotation()` | Ориентация экрана (0/90/180/270) |
| `Display_GetSize()` | Текущие размеры с учётом ориентации |
| `Display_SetWindow()` | Задать прямоугольное окно записи (CASET/RASET) — обязательный шаг перед записью пикселей |
| `Display_WritePixelsDMA()` | Передать буфер пикселей в окно (асинхронно; буфер должен жить до завершения передачи — не копируется) |
| `Display_FillColorDMA()` | Залить окно одним цветом (асинхронно, без буфера в SRAM — источник DMA не инкрементируется) |
| `Display_SleepIn()` / `Display_SleepOut()` | Сон / выход из сна контроллера |

Все статусы возврата — `Display_Status_t`: `DISPLAY_OK`, `DISPLAY_BUSY` (предыдущая передача не завершена), `DISPLAY_ERROR` (сбой на уровне периферии SPI/DMA либо координаты окна вне экрана).

## Реализация ST7789 (`st7789.c`)

- Физическое разрешение RAM контроллера: **240×320** (портретная ориентация "как есть"); текущие рабочий размер по умолчанию — `s_width=320`, `s_height=240` (альбомная).
- Передача данных — через DMA, побайтово через `write_command`/`write_data`/`write_data_u8`, либо чанками через `start_write_chunk()` для `Display_WritePixelsDMA`/`Display_FillColorDMA`.
- `s_fill_line[FILL_LINE_PIXELS]` — промежуточный буфер для заливки цветом одной "строкой" за DMA-транзакцию.
- `s_write_scratch[DISPLAY_WRITE_CHUNK_PIXELS]` — промежуточный буфер для передачи произвольных пикселей чанками (byte-swap для протокола, см. `byte_swap16`).
- Завершение DMA обрабатывается в `ST7789_OnDmaTxComplete()`, вызывается из `HAL_SPI_TxCpltCallback()`.
- Тайминги контроллера (задержки после reset/sleep out) вынесены в константы `ST7789_DELAY_*_MS` в `st7789.h`.
