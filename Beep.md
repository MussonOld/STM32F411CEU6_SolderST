# Beep

Неблокирующий зуммер: пин `BEEP` (PB2, выход push-pull). Модуль `App/Beep` (`beep.h` / `beep.c`).

## Полярность

`BEEP` — **активный высокий** (проверено на железе): низкий уровень = молчит. Начальный уровень — низкий (`.ioc`, `gpio.c`), т.е. зуммер молчит с момента сброса до `Beep_Init()`.

## Сигналы

Одновременно может играть только один сигнал: новый запрос, пока предыдущий не доигран, отклоняется (не накладывается и не удлиняет текущий).

| Функция | Что играет | Когда вызывается |
|---|---|---|
| `Beep_Alarm()` | 5 импульсов меандром 2 Гц (250 мс вкл/выкл), суммарно 2.5 сек | `Diag` — один сигнал на эпизод аварии, см. `Diag_Poll()`. Возвращает `false`, если сигнал уже играл — вызывающий обязан повторить запрос, иначе авария останется беззвучной |
| `Beep_ChannelEnabled()` | Один тон 0.1 сек | `Fsm` — короткий аккорд UP+DN включил канал, и на этот момент канал НЕ заблокирован аварией (`!Error_IsChannelBlocked`). Заблокированный канал и так уже сигналит `Beep_Alarm()`, второй сигнал не нужен |
| `Beep_EnteredSleep()` | Один тон 1 сек | `Sleep` — канал перешёл в `SLEEP_MODE_SLEEP` (фронт, не на каждый опрос), и только если канал включён (`State_IsEnabled`) — выключенному каналу сигнал не нужен |

`Beep_ChannelEnabled()`/`Beep_EnteredSleep()` не возвращают статус и не повторяют попытку сами: если в момент вызова уже играет другой сигнал, запрос молча теряется — это фидбэк, а не аварийное уведомление, повторять его не критично.

Все три функции сами проверяют флаг «Bzzz» (`SETTINGS_FLAG_BUZZER_BIT`, пункт сервисного меню) — при выключенном флаге ничего не играют. Вызывающий код об этом не знает и не должен.

## Устройство автомата

Внутри — общий механизм «N шагов по `step_ms` каждый, пин переключается между шагами»: `Beep_Alarm()` — 10 шагов по 250 мс (меандр, пин переключается на каждом шаге), `Beep_ChannelEnabled()`/`Beep_EnteredSleep()` — 1 шаг заданной длительности (пин включается один раз и гаснет по истечении, без меандра).

## Функции (`beep.h`)

| Функция | Назначение |
|---|---|
| `Beep_Init()` | Один раз после `MX_GPIO_Init()`. Выключает зуммер |
| `Beep_Poll()` | Из главного цикла, в 10 мс-гейте (`BEEP_POLL_MS`) |
| `Beep_Alarm()` | Запросить аварийный сигнал; `true` — принят (или намеренно подавлен флагом), `false` — занято, повторить позже |
| `Beep_ChannelEnabled()` | Запросить сигнал включения канала |
| `Beep_EnteredSleep()` | Запросить сигнал входа в сон |
| `Beep_IsActive()` | `true` — сейчас что-то играет |
